# V2.1 需求：专题、样品池与连续任务链

## 1. 范围

V2.1 面向超导量子计算测控组，继续使用桌面端、本地 SQLite、人工创建与分配任务。系统不接入 AI、手机端、登录、云同步或附件托管。现有 V1 与 V2 接口、数据和视图必须保持兼容。

## 2. 需求

- REQ-V21-001：来源小组可维护并作为专题的唯一来源；初始小组包括工艺组、读取组、量子门组、电子学组。
- REQ-V21-002：专题是持续工作的容器，记录名称、目的、双方联系人、我方对接人、状态和可选默认制冷机。
- REQ-V21-003：专题维护样品池；样品先填写规划标签和型号，编号可为空，后续可补临时或正式编号；同型号可建立多个样品。
- REQ-V21-004：专题维护按人工顺序排列的连续任务链；每个任务最多一个前置任务，支持插入、上移、下移和人工重排。
- REQ-V21-005：任务与样品为多对多；同一样品可参与同专题的多个任务；任务不得关联其他专题样品。
- REQ-V21-006：人员绑定任务整体而不是样品；任务至少一名成员，可指定一名协调负责人并配置多名参与人；每人预计工时按 0.5 小时递增。
- REQ-V21-007：任务制冷机为任务事实，专题可提供默认值；任务可显式待定；制冷机冲突只比较其他专题的活动任务。
- REQ-V21-008：样品维护初始 ETA、当前 ETA、pending、实际到样和历史；多样品任务的预计就绪日取需到样样品 ETA 的最大值，任一 pending 则受保护。
- REQ-V21-009：ETA、制冷机、任务日期、链顺序和人员集合变更均先预览、显示影响和冲突，再由人确认；不自动生成任务或分配人员。
- REQ-V21-010：专题总览提供测试中、延期、规定时间内到来、规定时间外到来、ETA pending 和已完成颜色；默认窗口为未来 7 个自然日，可设置 0～365 天；全部样品到样但未开始测试时主状态保持空白。
- REQ-V21-011：成果按任务提交，快照任务完整样品集合和验收清单；同一样品在不同任务中分别验收；成果可退回后按同一集合重提。
- REQ-V21-012：任务验收通过后完成；专题完成要求全部必做任务验收通过；个人进度和备注不因验收覆盖。
- REQ-V21-013：旧 V2 测控计划保留为兼容对象；复制为专题必须经过人工预览确认，不猜测旧任务顺序，不隐式同步。
- REQ-V21-014：数据库以 schema 3 增量迁移扩展，迁移前备份、事务化、幂等、校验失败停止并可用备份回滚。
- REQ-V21-015：V2.1 使用独立 `/api/v3` 与 `v3_*` 表；旧 `/api/v2` 的 34 个接口、V1 API、CSV、JSON、备份和旧负载算法保持不变。
- REQ-V21-016：1280×720 与 1366×768 桌面无页面级横向溢出，六个顶层区域保持互斥工具栏、抽屉和对话框焦点闭环。

## 3. 验收原则

需求必须同时通过服务端 API/迁移回归、V1/V2 兼容回归、任务链/样品/多人/验收场景和两种桌面分辨率验收。任何自动建任务、自动分配、移动端或 AI 行为均视为范围违规。
