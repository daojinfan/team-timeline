# V5 需求：三模块任务管理与执行

## 1. 目标

为超导量子计算测控组提供一个桌面端任务系统，用于维护基础资源、集中编辑专题与任务、通过甘特图安排任务和成员时间。系统不自动生成任务、不自动分配成员、不建设手机端。

## 2. 一级模块

### REQ-V5-001 资源维护

维护来源小组、测控成员、制冷机以及备份、导入、导出和恢复。资源支持启用/停用；停用资源不能用于新任务，但历史任务保留原名称。

### REQ-V5-002 任务全量编辑台

以专题为一级节点、任务为二级节点展示业务对象。专题和任务支持展开/收起、搜索、组合筛选和批量操作。

### REQ-V5-003 执行中心

以甘特图为主视图，按任务和成员展示排期、重叠和负载；支持修改任务整体时间和单个成员在任务中的时间。

## 3. 专题需求

- REQ-V5-004：专题只维护名称、目的、状态和备注。
- REQ-V5-005：专题状态为“正在进行”和“专题完成归档”。
- REQ-V5-006：专题删除必须防止丢失任务；有任务的专题必须先迁移任务或执行归档。
- REQ-V5-007：系统提供唯一的“无专题”系统分类，用于尚未完成归类的任务；该分类不可删除或归档。

## 4. 任务需求

- REQ-V5-008：任务属性包括任务编号、任务名称、来源小组、所属专题、测试目的、测试项、样品集合、测试时间计划、制冷机、参与成员、任务状态、备注和任务颜色。
- REQ-V5-009：不再区分负责人和参与成员；一个任务可以有零个或多个参与成员，未分配任务必须可保存并可筛选。
- REQ-V5-010：不保存每人工时、任务顺序、前置任务、联系人、项目标签、课题标签、制冷机待定开关或成果提交字段。
- REQ-V5-011：样品在任务编辑器中维护，当前可编辑字段为样品型号、样品编号、预期交付时间和样品备注；样品编号在交付前可以为空，填写编号表示已具备可识别的到样样品。样品可关联多个任务。历史规划标签、实际到样时间和 ETA 兼容字段保留在数据库中，但不在当前 V5 表单中新增或编辑。
- REQ-V5-012：任务颜色为人工标记色；状态颜色由系统固定映射，二者不互相替代。
- REQ-V5-028：测试项为任务内的可重复结构化条目，至少保存项目名称和备注，不引入成果提交或验收流程。
- REQ-V5-029：任务创建和编辑必须在一个编辑面板中完成；用户无需跳转到资源维护或执行中心才能补齐任务字段。

## 5. 状态需求

- REQ-V5-013：任务状态包括等待样品、样品交付延期、正在测试、测试延期和已完成。
- REQ-V5-014：正在测试和已完成由人手动切换。
- REQ-V5-015：任务未开始且样品 ETA 已过、样品编号仍为空时显示样品交付延期。
- REQ-V5-016：任务已经进入正在测试且当前时间超过计划结束时间、尚未完成时显示测试延期。
- REQ-V5-017：已完成优先级最高；样品状态不覆盖已完成状态。
- REQ-V5-030：任务关联多个样品时，任一必需样品已超过 ETA 且样品编号为空，任务即显示样品交付延期；ETA 为空或待确认不自动判延期。
- REQ-V5-031：系统不新增“已到样待测试”任务状态；未开始测试时仍处于等待样品阶段，另行显示到样进度。

## 6. 执行中心时间需求

- REQ-V5-018：任务整体时间为任务的计划开始日期和结束日期。
- REQ-V5-019：成员任务时间为该成员在具体任务中的参与日期范围，不包含工时。
- REQ-V5-020：拖拽任务整体时间时，系统必须询问是否同步全部参与成员。
- REQ-V5-021：拖拽成员任务时间时，只修改该成员日期；超出任务整体时间需给出扩展或保留独立日期的确认。
- REQ-V5-022：时间修改必须进行成员重叠、制冷机重叠、样品 ETA 和日期合法性预览，确认后写入。
- REQ-V5-032：新增参与成员时，成员日期默认等于任务整体日期；任务未排期时允许成员日期留空。
- REQ-V5-033：日期精度为天，按 Asia/Shanghai 当地日界计算；起止日期均包含当天。

## 7. 搜索、过滤与同步

- REQ-V5-023：任务编辑台支持任务、专题、样品、测试目的、测试项和备注搜索。
- REQ-V5-024：任务编辑台和执行中心支持来源小组、专题、状态、成员、样品、制冷机和日期组合筛选。
- REQ-V5-025：筛选后保留任务的专题祖先节点，隐藏无匹配专题并显示结果计数。
- REQ-V5-026：所有编辑入口使用同一任务事实；保存后任务树、专题、样品、执行中心和统计投影同步刷新。
- REQ-V5-027：重要归类、时间、成员、制冷机和状态修改写入操作日志，并支持一次撤销最近修改。
- REQ-V5-034：资源实体以稳定 ID 被任务引用；任意入口修改资源名称后，其他页面立即显示新名称，不复制出第二份名称。
- REQ-V5-035：已停用资源不出现在新关联默认选项中，但历史任务仍可显示并允许用户将其替换为启用资源。
- REQ-V5-036：任务测试目的、人工执行阶段和人工颜色的 canonical 名称分别为 `purpose`、`manual_phase` 和 `color`，不允许同一事实使用多套字段。
- REQ-V5-037：五类展示状态必须使用已冻结的状态颜色 token，同时保留中文文字和图标；任务人工颜色只做 accent，不覆盖状态色。
- REQ-V5-038：任务全量编辑台和执行中心必须分别支持配置默认状态筛选；每项可选择零个或多个五类展示状态，零个表示全部状态。
- REQ-V5-039：默认状态属于当前浏览器的工作区偏好，使用版本化本地存储；首次使用、配置损坏、版本不兼容或包含未知状态时必须回退到全部状态，不得影响任务事实或其他浏览器。
- REQ-V5-040：默认状态只在页面初始化或恢复默认偏好时应用；用户在视图内进行的临时筛选不得反向覆盖默认设置，并且必须提供恢复全部状态的操作。

## 8. 明确不建设

独立工作台、独立需求中心、独立样品管理、独立成果验收、联系人、AI 自动建任务、自动分配、手机端、登录权限、云同步和附件托管均不在 V5 范围内。
