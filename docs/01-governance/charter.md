# 项目章程

## 项目目的

把现有“小组任务管理与甘特图系统”改造成任务优先、操作路径清晰的桌面端本地管理工具，同时保持 Node.js、SQLite、CSV 和 JSON 数据兼容。

## 项目范围内

- 桌面端信息架构与页面外壳重构。
- 新建、完成、编辑、归档、恢复等核心任务流程优化。
- 甘特图智能范围、可操作空状态及视图专属工具栏。
- 加载、错误、撤销、筛选反馈及桌面偏好保存。
- 新数据库示例日期动态生成。
- API、客户端语法和 1280×720、1366×768 桌面验收。

## 项目范围外

- 手机端、触摸设备与移动端专用交互。
- 登录、权限、多用户实时协作和云部署。
- SQLite 表结构变更、数据迁移或导入导出不兼容调整。
- React、Vue 等前端框架重写。
- 推送远程、生产发布和部署。

## 成功标准

- 1280×720 桌面首屏可看到当前核心视图。
- 新建任务入口一次点击可达，查看逾期任务一次点击可达。
- 标记完成最多两步，编辑已完成任务不会改变其状态。
- 日志与维护视图不显示甘特图和批量任务控件。
- 现有 11 项 API 测试持续通过，并增加完成状态和动态示例数据回归测试。
- 现有 SQLite 数据、CSV 和 JSON 格式保持兼容。

## 约束

- 技术：保持 Node.js 原生 HTTP、node:sqlite 和原生 HTML/CSS/JavaScript；不新增运行时第三方依赖。
- 数据：不修改数据库表结构，不自动改写已有数据库。
- 安全/合规：继续定位为本地单用户工具，不扩大网络暴露范围。
- 时间和资源：TEAM_PROJECT；实现文件按所有权拆分，独立 Reviewer 执行 Release 两轮审核。
