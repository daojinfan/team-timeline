# 桌面工作区详细设计

## 页面层级

1. 固定顶部栏：项目名称、摘要、新建任务、数据菜单和刷新。
2. 单行可点击统计卡：成员、任务、进行中分配、逾期分配、重叠成员。
3. 主视图导航：甘特图、任务、负载、日志、维护。
4. 当前视图专属工具栏。
5. 两列工作区：可折叠成员栏和活动视图主体。
6. 任务详情按需使用右侧抽屉，未选中时不占布局宽度。

## 视图工具栏

- 甘特图：粒度、缩放、智能范围、今天、只看有任务成员、任务堆叠。
- 任务：关键词、成员、状态、日期、逾期、重叠、排序和卡片/列表。
- 负载：统计周期和成员筛选。
- 日志：关键词、类型和日期。
- 维护：仅显示备份、模板、导入、归档、回收站和维护操作。
- 批量栏只在至少选择一个任务时显示。

## 新建与详情

新建任务使用约 720px 的模态窗口，依次呈现基本信息、排期、成员与检查清单。任务详情抽屉宽约 360px，可关闭且不永久占据第三列。

## 桌面边界

正式验收分辨率为 1280×720 与 1366×768。不实施手机端、底部导航、触摸专用交互或移动端验收。
