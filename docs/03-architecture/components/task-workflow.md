# 任务工作流详细设计

## 创建

- 顶部“新建任务”一次点击打开模态窗口。
- 创建与保存模板不再二次确认。
- 提交期间禁用按钮；失败时保留输入并显示具体错误。

## 完成与重新打开

- 任务卡、任务列表和详情提供“标记完成”。
- 编辑和批量状态选项必须包含 `completed`。
- 编辑已完成任务时必须默认选择 `completed`，禁止无意回到自动状态。
- 完成只修改任务状态，不自动把个人分配进度改为 100%。低于 100% 时显示非阻塞提示。
- 已完成任务可重新设为自动、暂停或取消。

## 归档、删除和维护

- 归档和软删除成功后提供撤销入口。
- 永久维护或重置继续使用强确认，并在操作前返回备份。
- 任务和成员恢复继续沿用现有软删除接口。

## 筛选和偏好

统计卡可直接应用逾期或重叠筛选。客户端保存当前视图、甘特图粒度/缩放/范围、任务显示模式、排序和成员栏折叠状态。保存失败不得阻断业务操作。
