# V5 详细设计：任务全量编辑台与执行中心

## 1. 顶层导航

只保留三个一级入口：

1. 资源维护
2. 任务全量编辑台
3. 执行中心

不增加独立工作台、需求中心、样品管理和成果验收入口。

## 2. 资源维护

### 2.1 来源小组

列表字段：名称、启用状态、历史引用数。支持新增、修改、启用/停用和搜索。

### 2.2 测控成员

列表字段：姓名、基本角色、启用状态、当前任务数。支持新增、修改、启用/停用和搜索。成员参与任务及日期不在资源表维护。

### 2.3 制冷机

列表字段：名称、启用状态、历史引用数。支持新增、修改、启用/停用和搜索。

### 2.4 数据维护

保留备份、导入、导出和恢复；不提供联系人管理。

## 3. 任务全量编辑台

### 3.1 专题任务树

页面主体为可展开树：

~~~text
专题行
  └─ 缩进任务行
~~~

专题行显示名称、状态、任务数和匹配计数；任务行显示任务编号、任务名称、来源小组、状态、样品摘要、测试日期、制冷机和参与成员。支持单个展开/收起、全部展开/收起、拖动不改变顺序。

任务默认按开始日期升序、未排期任务最后、更新时间倒序显示；不保存任务顺序字段。

### 3.2 专题管理

专题表单只包含名称、目的、状态和备注。状态只能为“正在进行”和“专题完成归档”。

| 动作 | 规则 |
| --- | --- |
| 新增 | 名称必填；默认“正在进行” |
| 修改 | 在右侧编辑抽屉修改四个字段，保存后任务树原地刷新 |
| 归档 | 默认从“正在进行”列表隐藏，不改变任务本身状态 |
| 删除空专题 | 二次确认后删除 |
| 删除非空专题 | 必须选择目标专题，默认“无专题”；预览将移动的任务数后一次提交 |
| “无专题” | 系统节点，可查看和移出任务，不可删除、归档或改为其他名称 |

### 3.3 任务全量表单

任务行的“新增任务”和“编辑”都打开同一个宽屏抽屉。抽屉内分组而不分页，用户可在一处完成所有字段：

1. 归属：来源小组、所属专题
2. 基本信息：任务编号（只读）、任务名称、备注、任务颜色
3. 测试定义：测试目的、测试项名称和测试项备注
4. 样品集合：型号、编号、ETA、备注；支持新增和选择多个样品
5. 排期：任务开始日期、任务结束日期、制冷机
6. 参与成员：一个或多个成员，不区分负责人，不填写工时
7. 执行阶段：等待样品、正在测试、已完成；两类延期由系统计算
8. 保存预览：完整度提示、日期/制冷机/成员冲突和确认

允许保存不完整任务；缺失项以“待补充”标识。任务编号、版本、创建时间、更新时间和事件历史只读。

#### 3.3.1 字段矩阵

| 分组 | 字段 | 类型 | 新建默认/校验 | 列表展示 |
| --- | --- | --- | --- | --- |
| 只读 | 任务编号 | 系统生成文本 | 创建后不可改 | 是 |
| 归属 | 来源小组 | 单选资源 ID | 可空，空值标记待补充 | 是 |
| 归属 | 所属专题 | 单选专题 ID | 默认当前专题；全局新建时默认“无专题” | 由父节点表达 |
| 基本 | 任务名称 | 单行文本 | 必填，1～200 字符 | 是 |
| 基本 | 备注 | 多行文本 | 可空 | 按需展开 |
| 基本 | 任务颜色 | 预设色+无色 | 默认无色；仅作人工标记 | 细色条 |
| 测试 | 测试目的 | 多行文本 | 可空，空值标记待补充 | 摘要 |
| 测试 | 测试项 | 可重复结构 | 每项名称必填，可填备注；可拖动排列条目 | 数量+摘要 |
| 样品 | 样品集合 | 多选关联 | 可空；编辑器内可创建样品草稿 | 型号/编号摘要 |
| 排期 | 计划测试开始/结束 | 包含边界的日期 | 可空；两者均有值时开始不得晚于结束 | 是 |
| 排期 | 制冷机 | 单选资源 ID | 可空，空值标记待补充 | 是 |
| 人员 | 参与成员 | 多选资源 ID | 可为 0 人；新加成员默认使用任务日期 | 姓名/人数 |
| 执行 | 人工阶段 | waiting/testing/completed | 默认 waiting；testing 和 completed 需人工操作 | 显示计算后状态 |

不在表单中出现：负责人、每人工时、任务顺序、前置任务、联系人、本地对接人、项目/课题标签、专题默认制冷机、制冷机待定开关、成果提交及验收。

#### 3.3.2 样品内联编辑

用户在任务表单中可搜索已有样品，也可就地新增样品。正式编号未知时只填写样品型号；交付后在同一行补充样品编号，不创建第二个样品。样品备注用于记录型号之外的补充说明。

ETA 改动时保存原值、新值、修改时间和修改人。任务关联多样品时，表单列出型号、编号、ETA 和备注；不新增“已到样待测试”状态。历史实际到样日期继续保留，但不在当前 V5 表单中显示或编辑。

#### 3.3.3 保存级别

| 级别 | 条件 | 处理 |
| --- | --- | --- |
| 阻断 | 任务名为空、开始晚于结束、引用不存在对象、版本冲突 | 不保存，定位到字段 |
| 需确认 | 成员时间重叠、制冷机重叠、计划早于样品 ETA | 展示影响对象，用户确认后可保存 |
| 待补充 | 来源小组、测试目的、样品、排期、制冷机或成员缺失 | 允许保存，在任务行显示待补项数 |

### 3.4 搜索和过滤

搜索覆盖任务编号、名称、专题名称、样品标签/型号/编号、测试目的、测试项和备注。组合过滤支持来源小组、专题、状态、参与成员、制冷机、样品 ETA、任务日期、信息完整度。筛选后自动保留匹配任务的专题祖先，隐藏无匹配专题，显示结果计数和清除筛选按钮。

任务全量编辑台的默认状态集合可在资源维护的“工作区默认值”中配置。空集合表示全部状态；配置只在页面初始化或恢复默认偏好时写入当前筛选表达式，用户随后进行的快速筛选和组合筛选只影响当前会话状态，不更新默认值。

### 3.5 批量操作

支持批量修改来源小组、专题、制冷机、参与成员、状态和归档。所有批量操作先生成旧值/新值预览；涉及任务归属、状态、时间或样品的操作必须确认并写日志。

## 4. 执行中心

### 4.1 任务排期视图

显示任务整体时间条。拖拽整体任务条可平移；拖拽左右边缘可改开始/结束日期。保存前询问：

~~~text
同步所有参与成员的任务时间
仅修改任务整体时间
~~~

不同步时只更新任务整体日期。同步规则如下：

| 拖拽类型 | 任务日期 | 选择“同步所有成员”时 |
| --- | --- | --- |
| 整条平移 | 起止日同步平移 N 天 | 每个成员的起止日同步平移 N 天 |
| 修改左边界 | 只修改任务开始日 | 每个成员的开始日按相同天数改动，结束日不变 |
| 修改右边界 | 只修改任务结束日 | 每个成员的结束日按相同天数改动，开始日不变 |

若同步后某成员的开始日晚于结束日，预览标出该成员并要求用户选择“该成员日期设为新任务日期”或取消；不做静默截断。

### 4.2 成员负载视图

按成员显示该成员参与的任务时间片。拖拽成员时间片只修改该成员日期，不改变其他成员或任务整体日期。若成员日期超出任务整体时间，提示“扩展任务整体时间”或“保留成员独立日期”。

无每人工时后，负载按任务数量、日期覆盖和重叠数量计算，不显示小时数。

### 4.3 执行操作

允许人工执行“开始测试”和“标记完成”。测试延期由当前时间超过任务结束日期自动显示；样品交付延期由样品 ETA 自动显示。

#### 4.3.1 显示状态判定表

| 顺序 | 条件 | 显示状态 |
| --- | --- | --- |
| 1 | 人工阶段 = completed | 已完成 |
| 2 | 人工阶段 = testing，且结束日存在，且当地日期 > 结束日 | 测试延期 |
| 3 | 人工阶段 = testing | 正在测试 |
| 4 | 人工阶段 = waiting，且任一必需样品编号为空、ETA 已确认且当地日期 > ETA | 样品交付延期 |
| 5 | 其他 | 等待样品 |

没有样品、ETA 为空、ETA 待确认或全部样品均已有编号时，不会自动触发样品交付延期。全部样品已有编号但未开始测试时仍显示“等待样品”。

### 4.4 执行过滤

支持时间范围、来源小组、专题、参与成员、状态、制冷机、只看延期、只看冲突、只看未分配和只看未排期。

执行中心拥有独立于任务全量编辑台的默认状态集合；初始化规则与 §3.4 相同。执行中心其他视图状态（甘特图/任务/负载、时间单位、粒度和范围）不属于本次默认状态配置。

## 4.5 工作区默认值

- 设置入口位于资源维护，避免新增第四个一级导航。
- “任务全量编辑台默认状态”和“执行中心默认状态”均使用五类展示状态复选项，允许零选、多选和全选。
- 保存使用版本化键 `teamTaskGantt.v5Prefs.v1`，结构只包含 `version`、`editorDefaultStatuses` 和 `executionDefaultStatuses`。
- 读取时必须校验对象结构、版本和状态枚举；任何非法值使该项回退为空集合。读写失败不得阻断 V5 数据加载。
- 点击“恢复全部状态”会把两个默认集合置空、保存配置，并立即把两个视图的当前状态筛选恢复为全部状态。
- 保存默认值后立即应用到两个视图的当前状态筛选；其他筛选条件保持不变。
- 默认值是界面偏好，不写入任务、事件、资源或 SQLite，不通过 V5 API 传输。

## 5. 同步与冲突

所有保存使用任务版本号校验；并发修改时返回版本冲突并重新加载。时间保存预览成员日期重叠、制冷机重叠、样品 ETA 与任务日期关系和日期合法性。保存成功后刷新任务树、专题状态、样品状态和执行中心投影，并提供一次撤销最近修改。

### 5.1 资源同步

任务只保存来源小组、成员和制冷机 ID。资源改名后，服务端使资源读模型失效，并向当前会话发送资源已变更事件；任务编辑台和执行中心重新解析名称。历史日志保存当时的名称快照供审计，不作为当前页面显示源。

### 5.2 撤销边界

仅可撤销当前用户本会话最近一次成功的任务归类、时间、参与成员、制冷机或状态变更。若目标对象在该操作后又被修改，撤销入口失效并说明原因；不对导入、恢复和批量归档提供单步撤销。

## 6. 删除和历史

专题、来源小组、成员和制冷机默认停用/归档，不物理删除仍被历史引用的记录。任务不提供物理删除入口；归档任务从默认列表隐藏但保留编号和日志。

## 7. 无障碍与桌面边界

状态颜色必须同时显示中文标签；筛选结果、冲突预览和错误信息使用可访问文本。1280×720 和 1366×768 下页面无级联横向滚动，树和甘特图只在自身容器内滚动。

### 7.1 状态颜色 token

状态标签使用下列固定的前景色与背景色（轻色桌面）；实现不得用任务自定义色替换这些 token。配色的对比度应满足 WCAG AA 4.5:1；回归测试必须按 token 值检查。

| 显示状态 | Token | 前景色 | 背景色 | 辅助标识 |
| --- | --- | --- | --- | --- |
| 等待样品 | `status.waiting` | `#0F172A` | `#E2E8F0` | 文字“等待样品” |
| 样品交付延期 | `status.sample-delayed` | `#7F1D1D` | `#FEE2E2` | 文字+延期图标 |
| 正在测试 | `status.testing` | `#1E3A8A` | `#DBEAFE` | 文字+进行中图标 |
| 测试延期 | `status.test-delayed` | `#7C2D12` | `#FFEDD5` | 文字+警告图标 |
| 已完成 | `status.completed` | `#14532D` | `#DCFCE7` | 文字+完成图标 |

任务的 `color` 只渲染任务行和甘特图条左侧 4px accent 条；任务状态 chip 始终使用上表 token。任务颜色与状态色同时出现时，两者不覆盖；无任务颜色时隐藏 accent 条。

## 8. 页面级交互流程

### 8.1 新建任务

1. 用户在全局顶部或某专题行点击“新增任务”。
2. 系统生成任务编号，预填当前专题或“无专题”，打开全量编辑抽屉。
3. 用户可在抽屉内新建规划样品、选成员和制冷机，无需跳转页面。
4. 点击保存后先显示阻断错误、待确认冲突和待补充项；用户确认后原子提交。
5. 树中定位并高亮新任务，执行中心投影同步可见。

### 8.2 重新归类

1. 单任务使用“移动到专题”；多任务使用批量更改所属专题。
2. 目标选择包含“无专题”和所有正在进行的专题；已归档专题需主动展开后才可选。
3. 预览显示原专题、目标专题和影响任务数；确认后统一移动。
4. 任务行移入新专题节点，记录一条可撤销的归类事件。

### 8.3 甘特图改期

1. 拖拽期间显示新起止日、变化天数和影响成员数。
2. 松开后打开变更预览，先选“同步所有成员”或“仅修改任务”。
3. 预览按阻断、冲突警告、信息提示分组，列出成员和制冷机重叠。
4. 确认后一次更新任务与需同步的成员日期；失败时回退整次变更。

## 9. 实现接口边界

后续实现应将下列操作建模为服务端命令，页面不直接拼接多表写入：

| 命令 | 原子写入范围 | 必要预览 |
| --- | --- | --- |
| `CreateTask` / `UpdateTask` | 任务、测试项、样品关联、成员关联 | 完整度、日期、重叠 |
| `MoveTasksToTopic` | 任务所属专题、事件日志 | 任务数和新旧专题 |
| `DeleteTopicAndMoveTasks` | 任务迁移、专题删除、事件日志 | 目标专题和影响任务 |
| `ChangeTaskSchedule` | 任务日期、可选的全部成员日期 | 成员/制冷机重叠、ETA |
| `ChangeMemberSchedule` | 单个任务成员日期、可选的任务边界 | 是否超出任务日期 |
| `StartTesting` / `CompleteTask` | 人工执行阶段、事件日志 | 日期和样品信息提示 |
| `RenameOrDisableResource` | 单一资源、版本号 | 历史引用数 |

返回错误至少区分：字段校验失败、版本冲突、引用已停用/不存在、预览已过期和未知系统错误。预览必须携带短时效令牌，正式提交时重新校验对象版本，防止用户确认后对象已被其他操作改变。
