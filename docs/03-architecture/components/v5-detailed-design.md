# V5 详细设计：任务全量编辑台与执行中心

## 1. 顶层导航

只保留三个一级入口：

1. 资源维护
2. 任务全量编辑台
3. 执行中心

不增加独立工作台、需求中心、样品管理和成果验收入口。

## 2. 资源维护

### 2.1 来源小组

列表字段：名称、启用状态、历史引用数。支持新增、修改、启用/停用和搜索。

### 2.2 测控成员

列表字段：姓名、基本角色、启用状态、当前任务数。支持新增、修改、启用/停用和搜索。成员参与任务及日期不在资源表维护。

### 2.3 制冷机

列表字段：名称、启用状态、历史引用数。支持新增、修改、启用/停用和搜索。

### 2.4 数据维护

保留备份、导入、导出和恢复；不提供联系人管理。

## 3. 任务全量编辑台

### 3.1 专题任务树

页面主体为可展开树：

~~~text
专题行
  └─ 缩进任务行
~~~

专题行显示名称、状态、任务数和匹配计数；任务行显示任务编号、任务名称、来源小组、状态、样品摘要、测试日期、制冷机和参与成员。支持单个展开/收起、全部展开/收起、拖动不改变顺序。

任务默认按开始日期升序、未排期任务最后、更新时间倒序显示；不保存任务顺序字段。

### 3.2 专题管理

专题表单只包含名称、目的、状态和备注。状态只能为“正在进行”和“专题完成归档”。有任务的专题删除前必须迁移任务或归档。

### 3.3 任务表单

任务表单分为：

1. 归属：来源小组、所属专题
2. 基本信息：任务编号（只读）、任务名称、备注、任务颜色
3. 测试定义：测试目的、测试项、每项验收要求和备注
4. 样品集合：规划标签、型号、编号、ETA、到样信息；支持新增和选择多个样品
5. 排期：任务开始日期、任务结束日期、制冷机
6. 参与成员：一个或多个成员，不区分负责人，不填写工时
7. 状态：等待样品、样品交付延期、正在测试、测试延期、已完成
8. 保存预览：完整度提示、日期/制冷机/成员冲突和确认

允许保存不完整任务；缺失项以“待补充”标识。任务编号、版本、创建时间、更新时间和事件历史只读。

### 3.4 搜索和过滤

搜索覆盖任务编号、名称、专题名称、样品标签/型号/编号、测试目的、测试项和备注。组合过滤支持来源小组、专题、状态、参与成员、制冷机、样品 ETA、任务日期、信息完整度。筛选后自动保留匹配任务的专题祖先，隐藏无匹配专题，显示结果计数和清除筛选按钮。

### 3.5 批量操作

支持批量修改来源小组、专题、制冷机、参与成员、状态和归档。所有批量操作先生成旧值/新值预览；涉及任务归属、状态、时间或样品的操作必须确认并写日志。

## 4. 执行中心

### 4.1 任务排期视图

显示任务整体时间条。拖拽整体任务条可平移；拖拽左右边缘可改开始/结束日期。保存前询问：

~~~text
同步所有参与成员的任务时间
仅修改任务整体时间
~~~

同步时更新任务整体日期和所有成员日期；不同步时只更新任务整体日期。

### 4.2 成员负载视图

按成员显示该成员参与的任务时间片。拖拽成员时间片只修改该成员日期，不改变其他成员或任务整体日期。若成员日期超出任务整体时间，提示“扩展任务整体时间”或“保留成员独立日期”。

无每人工时后，负载按任务数量、日期覆盖和重叠数量计算，不显示小时数。

### 4.3 执行操作

允许人工执行“开始测试”和“标记完成”。测试延期由当前时间超过任务结束日期自动显示；样品交付延期由样品 ETA 自动显示。

### 4.4 执行过滤

支持时间范围、来源小组、专题、参与成员、状态、制冷机、只看延期、只看冲突、只看未分配和只看未排期。

## 5. 同步与冲突

所有保存使用任务版本号校验；并发修改时返回版本冲突并重新加载。时间保存预览成员日期重叠、制冷机重叠、样品 ETA 与任务日期关系和日期合法性。保存成功后刷新任务树、专题状态、样品状态和执行中心投影，并提供一次撤销最近修改。

## 6. 删除和历史

专题、来源小组、成员和制冷机默认停用/归档，不物理删除仍被历史引用的记录。任务不提供物理删除入口；归档任务从默认列表隐藏但保留编号和日志。

## 7. 无障碍与桌面边界

状态颜色必须同时显示中文标签；筛选结果、冲突预览和错误信息使用可访问文本。1280×720 和 1366×768 下页面无级联横向滚动，树和甘特图只在自身容器内滚动。
