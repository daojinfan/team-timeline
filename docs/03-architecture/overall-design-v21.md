# V2.1 总体设计

## 1. 领域层级

```text
来源小组 1 ── N 专题
专题 1 ── N 样品
专题 1 ── N 连续任务
任务 M ── N 样品
任务 M ── N 人员
任务 1 ── N 成果 ── 0..1 人工验收
```

样品属于专题样品池，可重复参与同专题多个任务；人员绑定任务整体，不建立样品级人员字段。连续任务链采用线性 finish-to-start 关系，先不引入分支 DAG。

## 2. 事实归属

| 事实 | 权威对象 |
| --- | --- |
| 来源、目的、联系人 | 专题 |
| 型号、规划标签、编号、ETA、到样 | 样品 |
| 开始/结束日期、执行状态、制冷机 | 任务 |
| 成员、协调负责人、个人工时 | 任务成员关系 |
| 结果、清单、验收 | 任务成果快照 |

制冷机可以由专题作为创建默认值，但实际冲突和变更均以任务级事实为准。任务就绪日为所有需到样样品 ETA 的最大值；ETA pending 时不能计算平移。

## 3. V2 兼容岛

现有 `v2_control_plans`、`v2_plan_tasks`、V2 schema checksum、34 个 `/api/v2` 路由和 V1 任务/负载语义冻结不变。V2.1 增量创建 schema 3 和 `/api/v3`，不向旧表隐式双写。旧计划通过“复制为专题”预览确认建立一次性引用与新对象，之后两边独立。

## 4. 桌面信息架构

保留工作台、专题规划、人工分配、执行中心、成果验收、资源维护六个顶层区域。专题规划内部提供概览、样品池、任务链；历史 V2 测控计划作为同一区域的兼容子页。专题详情使用 420px 快速抽屉，样品池、任务链编辑与验收使用不超过 720px 的对话框或主工作区。

## 5. 非目标

无 AI、无自动任务生成、无自动人员分配、无手机端、无登录、多用户权限、云部署和二进制附件托管。
