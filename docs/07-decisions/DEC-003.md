# DEC-003：V2.1 专题与连续任务模型

## 决策

V2.1 使用独立 V3 模型承载“来源小组→专题→样品池→连续任务链”。样品与任务、任务与人员均为多对多；制冷机以任务为事实归属，专题仅提供默认值；任务链先采用线性 finish-to-start；任务至少一名成员，可指定协调负责人；成果以任务完整样品集合快照并人工验收。

## 原因

现有 V2 计划把样品、ETA、到样和制冷机固化在单计划上，无法无损表达多样品、多任务复用和任务级制冷机。直接改写 V2 会破坏已验证的 API、schema checksum、甘特图和负载语义。独立 V3 可以让新模型完整表达业务，同时保留旧系统兼容。

## 约束

任何旧计划转换必须预览、人工确认并记录映射；不得按日期或 ID 猜测任务顺序，不得隐式双写，不得自动建任务或分配人员。接口、数据、迁移、安全或验收契约发生变化时必须回到 PM 重新批准。
