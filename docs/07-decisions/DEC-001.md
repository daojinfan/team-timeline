# DEC-001：桌面端原生架构与兼容性边界

## 决定

本期只优化桌面端，继续使用 Node.js 原生 HTTP、`node:sqlite` 和原生 HTML/CSS/JavaScript。不引入前端框架或运行时第三方依赖，不修改 SQLite 表结构、公共 API 路径、CSV 列和 JSON 备份结构。

## 理由

当前功能已经完整，主要问题是桌面信息架构和操作路径。保持技术与数据边界可以把风险集中在可验证的 UX 改造，并确保已有本地数据继续使用。

## 后果

- 前端通过冻结文件所有权并行修改 `index.html`、`styles.css` 和 `app.js`。
- 完成状态复用现有 API；个人进度保持独立。
- 手机端、认证、实时协作、云部署和数据迁移不在本期范围。

## 批准

人类负责人已于 2026-08-20 确认总体设计和详细设计。
