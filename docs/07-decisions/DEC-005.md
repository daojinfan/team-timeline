# 决策：V5 工作区默认状态可配置

## 决策内容

任务全量编辑台和执行中心分别提供可配置的默认状态筛选，默认保持“全部状态”，配置按当前浏览器保存，不改变业务数据、SQLite schema 或 V5 API。

## 背景

当前两个 V5 视图的状态筛选均在前端初始化为固定空值，用户每次进入页面都要重新选择关注的状态。该偏好属于展示层，不应写入任务事实或影响其他用户。

## 已考虑的方案

1. **浏览器本地偏好（采用）**：在资源维护中提供“工作区默认值”设置，使用版本化 `localStorage` 保存任务全量编辑台和执行中心各自的默认状态集合。
2. **SQLite/服务端共享配置**：增加设置表和 API，让同一数据库的所有浏览器共享默认值。
3. **仅保留当前会话状态**：刷新页面后恢复固定默认值。

## 依据和权衡

当前应用是本地单用户工具，没有登录和云同步；浏览器本地偏好足以满足个性化需求，并且不引入数据库迁移、公共 API 变化或跨用户覆盖风险。空集合继续表示“全部状态”，损坏或旧版本配置自动回退到全部状态。

## 影响

- 需求：REQ-V5-038～040 增加默认筛选偏好语义。
- 总体/领域/组件设计：ARC-COMP-V5-001 增加工作区默认值入口、初始化和重置规则。
- 接口/数据/安全：不修改数据库、V5 API、历史数据或兼容投影；仅使用浏览器本地存储。
- 工作包：新增 WP-013，绑定 CR-009。
- 测试/验证证据：增加 V5 默认状态配置静态回归，并运行 `npm test`、`node --check public/app.js`。
- 运行/发布：仅影响本地桌面 Web 工作区，无远程发布。
