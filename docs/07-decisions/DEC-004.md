# DEC-004：V4 专题模块唯一工作区与人工连续任务序列

## 决策

V4 保留六个顶层区域，但将“专题规划”确定为专题、样品和连续任务的唯一管理工作区。工作台只承担总览和导航；人工分配、执行中心和成果验收分别承担跨专题分配、执行跟踪和成果验收，并通过同一事实模型回到专题工作区。

专题主工作区使用“概览、样品池、连续任务”三个子页。样品先以规划标签和型号进入样品池，编号可以后补；连续任务是人工排序序列，不建立用户可见的前置任务或 `finish-to-start` 依赖。任务与样品保持多对多，成员绑定任务整体，制冷机以任务级事实为准，专题制冷机只作为新任务默认值。

所有编辑入口使用统一任务全量编辑台和统一专题/样品编辑器。任何入口保存后，专题工作区、工作台、人工分配、执行中心和成果验收重新读取同一份 V3 数据，禁止维护页面私有副本。

## 原因

当前 V3 数据模型已经能够表达用户的业务关系，主要问题是导航和编辑语义分散。使用无数据模型变更的 V4 Option A 可以先消除认知负担和同步缺陷，同时避免破坏已验证的 V2/V3 接口兼容性。

## 后果

- 专题列表只有一个完整管理入口；工作台列表是摘要投影。
- 任务顺序可调整，但顺序不再被解释为自动阻塞关系；任务是否可执行仍由人工决定。
- 到样窗口和颜色是专题规划的统一筛选与状态语言，默认 7 天，可在桌面端调整。
- 未持久化的本地联络人字段不在 V4 UI 中出现；如要保存必须另立数据变更。
- V4 需要新增桌面交互回归和双分辨率验收，但不需要 schema 迁移或接口版本升级。

## 兼容约束

DEC-003 关于独立 V3 模型、人工创建/分配、任务级制冷机、成果快照和 V2 兼容岛的约束继续有效；本决策仅修正专题模块的信息架构和用户可见任务顺序语义。
