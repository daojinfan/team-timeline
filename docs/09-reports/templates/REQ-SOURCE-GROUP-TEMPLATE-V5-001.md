# 集成测试组-测控任务需求文档

## 1. 为什么需要这个文档

测试需求如果只停留在口头或聊天记录中，容易遗漏边界、重复沟通，也无法判断集成测试组当前是否有能力承接。提交这份文档，是为了让需求更正式地进入承接评估：来源方说明“来自哪个项目、要解决什么问题、主要测什么”，集成测试组据此评估测试范围、总体工作量和可用资源，再决定是否承接以及如何排期。

| 这份文档需要回答的问题 | 对应填写位置 |
| --- | --- |
| 需求来自哪里 | 基本信息：项目名称、来源小组 |
| 测试目的是什么 | 为后续测试任务起指导作用 |
| 测试边界到哪里 | 测试对象和主要的测试内容 |

## 2. 基本信息

| 字段 | 填写内容（请直接替换提示文字） |
| --- | --- |
| 项目名称（必填） | 请填写需求所属项目名称,决定任务优先级 | 
| 来源小组（必填） | 如：工艺组 / 读取组 / 量子门组等 |
| 任务名称（必填） | 请填写本次希望集成测试组承接的任务名称 |
| 样品类型（必填） | 请填写样品类型，比特样品，腔样品 |
| 样品型号或版本（必填） | 请填写已知型号或版本；未知则填“待定，交付后补充” |
| 样品数量（必填） | 请填写数量或范围，例如“2个”或“预计1～2个” |
| 样品编号 | 请填写编号；尚未产生编号则填“待定，交付后补” |
| 预计样品交付时间（必填） | 请填写日期或时间范围；完全不确定则填“待定，等待加工确认” |
| 制冷机是否已协调（必填） | 请填写：已协调 / 协调中 / 未协调 |
| 已协调的制冷机 | 已协调时填写制冷机名称；未协调则填“由集成测试组确认” |
| 其他已确定信息 | 请填写已确认的测试条件、特殊限制或交付要求；没有则填“无” |

## 3. 测试目的
这一部分用于说明为什么需要本次测试、希望解决什么问题，以及测试结果将如何使用。填写时尽量写清楚“为什么测、要判断什么、结果支持什么决定”；暂时无法确定时填“待双方确认”。

| 内容 | 填写内容（请直接替换提示文字） |
| --- | --- |
| 测试任务背景或重要性（必填） | 请填写为什么需要开展本次测试，以及它对项目或后续工作的作用 |
| 测试目的（必填） | 请填写本次测试要解决的问题，或希望验证的关键判断 |
| 预期结论或结果用途（可选） | 请填写希望测试结果支持的决定，例如设计确认、工艺比较或后续测试安排；不确定则填“待双方确认” |

## 4. 测试对象和主要的测试项
### 测试对象描述
1. 对样品进行基本的描述：如多少路读取，多少个比特，具体测试哪几路
2. 需要测控工程师负责装样的，最好能够给出具体的接线表，若无法给出接线表，则应给出足以生成接线表的相关信息，由测控工程师给出具体的接线表后与需求方确认

### 主要的测试项
1. 根据测试目的，分解出主要的测试项来说明测试目的需要得到的结论
2. 若对测试项有特别要求需提前提出，测控工程师根据主要测试项生成测试大纲与需求方确认

建议文件名：`项目名称-任务名称-测控任务需求-提交日期.md`
