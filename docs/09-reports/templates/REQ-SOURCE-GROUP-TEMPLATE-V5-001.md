# 其他小组测试需求单（简版）

## 这份文档为什么需要

这份需求单用于把其他小组的测试需求集中记录下来，避免需求只存在于口头沟通或聊天记录中。它只收集测控组开始规划所必需的信息：

- 知道“哪个小组要测什么”；
- 知道“为什么测、要看哪些测试项”；
- 知道“有哪些样品、什么时候大致能到”；
- 样品还没有正式编号时，也可以先做专题、任务和排期规划。

需求单提交后，测控组会再确认专题、拆分任务、安排成员、选择制冷机和制定正式测试时间。需求方不需要填写这些内部管理信息。

## 填写要求

已经明确的信息直接填写；暂时不明确的信息不要空着，按下面的方式填写，并尽量补充已知范围或原因。

| 不明确的内容 | 建议填写方式 | 示例 |
| --- | --- | --- |
| 测试目的还不完整 | 写“要解决的问题”或“希望得到的判断” | `确认该封装是否满足后续读出测试要求` |
| 测试项还没完全确定 | 先写已知方向，后面加“待测控组确认” | `Q值测试，具体指标待测控组确认` |
| 不知道归入哪个专题 | 填 `不清楚，由测控组归类` | `不清楚，由测控组归类` |
| 样品还没有正式编号 | 填 `待定，交付后补` | `待定` |
| 样品数量还没定 | 填暂定数量或范围 | `暂定2个`、`预计1～2个` |
| 交付时间还没定 | 填预计时间范围或 `待定`，并写原因 | `预计9月上旬`、`待定，等待加工确认` |
| 不知道用哪台制冷机 | 填 `无特殊要求，由测控组确认` | `无特殊要求，由测控组确认` |

## 提交后怎么处理

1. 提出小组填写本页并提交。
2. 测控组确认需求内容；信息不足时只补充需要确认的部分。
3. 测控组内部完成专题归类、任务拆分、成员安排、制冷机选择和测试时间排期。
4. 预计交付时间或制冷机发生变化时，直接反馈给测控组更新。
