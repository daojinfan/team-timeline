# 其他小组测试需求单（数字填写版）

## 使用说明

本需求单用于把口头、聊天中的测试需求集中记录下来，便于测控组提前确认、排期和分配资源。提交时只需填写当前已经明确的信息；样品编号等暂时未知的信息不影响提前规划，但必须按下表写明当前情况。

| 填写要求 | 说明 |
| --- | --- |
| 必须填写 | 来源小组、需求名称、测试目的、至少一个测试项，以及样品型号、数量、样品编号和预计交付时间。 |
| 信息暂不明确 | 不要留空，请使用“待定，交付后补”“待定，等待加工确认”等明确表述。 |
| 测控组内部处理 | 专题归类、任务拆分、参与成员、制冷机、任务状态、颜色和甘特图由测控组在系统内维护。 |

填写时请直接替换表格中的“请填写……”提示文字；有多个测试项或多个样品时，复制相应表格行继续填写。

## 不明确时怎么填

| 当前情况 | 直接填写 |
| --- | --- |
| 测试目的还不完整 | 请填写要解决的问题或希望得到的判断。 |
| 测试项尚未完全确定 | 请填写已知方向；具体指标待测控组确认。 |
| 不清楚属于哪个专题 | 不清楚，由测控组归类。 |
| 样品编号暂时未知 | 待定，交付后补。 |
| 样品数量暂时不确定 | 填写估计值或范围，例如“暂定2个”或“预计1～2个”。 |
| 预计交付时间不确定 | 填写已知时间范围，例如“预计9月上旬”；完全未知时填写“待定，等待加工确认”。 |
| 不确定使用哪台制冷机 | 无特殊要求，由测控组确认。 |

## 1. 需求信息

| 字段 | 填写内容（请直接替换提示文字） |
| --- | --- |
| 提出小组（必填） | 请填写：工艺组 / 读取组 / 量子门组 / 电子学组 / 其他（保留一项） |
| 需求名称（必填） | 请填写需求名称 |
| 测试目的（必填） | 请填写要解决的问题或希望得到的判断 |
| 专题建议（可选） | 请填写已有或建议专题；不清楚则填“不清楚，由测控组归类” |
| 制冷机要求（可选） | 请填写偏好或限制；没有则填“无特殊要求，由测控组确认” |
| 其他说明（可选） | 请填写；没有则填“无” |

## 2. 测试项

每个测试项填写一行；需要增加时，复制表格中的填写行。

| 测试项（必填） | 关注内容或说明 |
| --- | --- |
| 请填写测试项，例如“Q值测试” | 请填写关注点；不清楚则填“具体指标待测控组确认” |
| 请按需填写另一项；没有则删除本行 | 请填写关注点；不清楚则填“具体指标待测控组确认” |

## 3. 样品信息

每种或每批样品填写一行；需要增加时，复制表格中的填写行。样品编号未知时仍可提交，用统一表述说明即可。

| 样品代称（可选） | 样品型号（必填） | 数量（必填） | 样品编号（必填） | 预计交付时间（必填） | 备注（可选） |
| --- | --- | --- | --- | --- | --- |
| 请填写，例如“BGA-01” | 请填写样品型号 | 请填写数字或范围，例如“2”或“1～2” | 请填写编号；未知则填“待定，交付后补” | 请填写日期、时间范围，或“待定，等待加工确认” | 请填写；没有则填“无” |
| 请按需填写另一批；没有则删除本行 | 请填写样品型号 | 请填写数字或范围 | 请填写编号；未知则填“待定，交付后补” | 请填写日期、时间范围，或“待定，等待加工确认” | 请填写；没有则填“无” |

## 提交后怎么处理

| 步骤 | 处理人 | 处理内容 |
| --- | --- | --- |
| 1 | 来源小组 | 填写并提交本需求单。 |
| 2 | 测控组 | 与来源小组确认测试目的、测试项、样品和时间等必要信息。 |
| 3 | 测控组 | 在系统中归入专题、拆分任务，并安排参与成员、制冷机、状态、颜色和甘特图。 |
| 4 | 双方 | 样品交付时间、数量或测试要求发生变化时，及时同步变更。 |

建议文件名：`来源小组-需求名称-提交日期.md`
