# 集成测试组-测控任务需求文档

## 1. 为什么需要这个文档

测试需求如果只停留在口头或聊天记录中，容易遗漏边界、重复沟通，也无法判断集成测试组当前是否有能力承接。提交这份文档，是为了让需求更正式地进入承接评估：来源方说明“来自哪个项目、要解决什么问题、主要测什么”，集成测试组据此评估测试范围、总体工作量和可用资源，再决定是否承接以及如何排期。

| 这份文档需要回答的问题 | 对应填写位置 |
| --- | --- |
| 需求来自哪里 | 基本信息：项目名称、来源小组 |
| 这次要解决什么问题 | 测试对象与测试目的 |
| 测试边界到哪里 | 测试对象、覆盖范围和不包含内容 |
| 主要要做哪些工作 | 主要测试项、样品数量、测试条件和重复次数 |
| 集成测试组能否承接 | 由集成测试组根据本文档评估工作量、制冷机和成员资源后确认 |

本文档不是测试报告，也不要求需求方填写集成测试组内部的专题、任务拆分、成员排班或甘特图。填写时直接替换表格里的“请填写……”提示；暂时不确定的内容按提示写明“待定”或“由双方确认”，不要留空。

## 2. 基本信息

| 字段 | 填写内容（请直接替换提示文字） |
| --- | --- |
| 项目名称（必填） | 请填写需求所属项目名称 |
| 来源小组（必填） | 请填写：工艺组 / 读取组 / 量子门组 / 电子学组 / 其他 |
| 任务名称（必填） | 请填写本次希望集成测试组承接的任务名称 |
| 样品类型（必填） | 请填写样品类型，例如芯片、封装样品或器件 |
| 样品型号或版本（必填） | 请填写已知型号或版本；未知则填“待定，交付后补充” |
| 样品数量（必填） | 请填写数量或范围，例如“2个”或“预计1～2个” |
| 样品编号 | 请填写编号；尚未产生编号则填“待定，交付后补” |
| 预计样品交付时间（必填） | 请填写日期或时间范围；完全不确定则填“待定，等待加工确认” |
| 制冷机是否已协调（必填） | 请填写：已协调 / 协调中 / 未协调 |
| 已协调的制冷机 | 已协调时填写制冷机名称；未协调则填“由集成测试组确认” |
| 其他已确定信息 | 请填写已确认的测试条件、特殊限制或交付要求；没有则填“无” |

## 3. 测试对象与测试目的

这一部分用于明确“测什么、在什么范围内测、希望通过测试得到什么”。描述应具体到样品、版本、批次、条件或判定方向；暂时没有的边界可以写“待双方确认”。

| 内容 | 填写内容（请直接替换提示文字） |
| --- | --- |
| 测试对象（必填） | 请填写要测试的样品、型号、版本或批次 |
| 覆盖范围（必填） | 请填写本次覆盖的样品数量、测试条件、温区或其他范围 |
| 不包含的内容（可选） | 请填写明确不在本次任务内的内容；没有则填“无” |
| 测试目的（必填） | 请填写要解决的问题，以及测试完成后希望得到的判断 |
| 重点关注或判定方向（可选） | 请填写需要重点观察的指标、现象或通过条件；不清楚则填“由双方确认” |
| 预期结果用途（可选） | 请填写结果将用于设计确认、工艺比较、后续测试或其他决策；不确定则填“待确认” |

## 4. 主要的测试项

请根据上一部分的测试目的填写主要测试项，不必在需求阶段写成完整测试方案。每个测试项填写一行；需要增加时，复制表格中的填写行。测试项、样品数量、条件和重复次数越明确，越便于集成测试组评估总体工作量。

| 主要测试项（必填） | 对应的测试目的或要回答的问题 | 主要条件或范围 | 样品数/重复次数 | 备注 |
| --- | --- | --- | --- | --- |
| 请填写测试项，例如“Q值测试” | 请填写该项要验证什么；不清楚则填“由双方确认” | 请填写已知条件；不确定则填“待确认” | 请填写数量或次数；不确定则填“待确认” | 请填写特殊要求；没有则填“无” |
| 请按需填写另一项；没有则删除本行 | 请填写该项要验证什么 | 请填写已知条件 | 请填写数量或次数 | 请填写；没有则填“无” |

## 5. 需求提交后的处理

| 步骤 | 处理人 | 处理内容 |
| --- | --- | --- |
| 1 | 需求来源方 | 填写并提交本需求文档，说明当前已知信息和不确定项。 |
| 2 | 集成测试组 | 根据测试对象、目的和主要测试项，确认边界并评估总体工作量与资源。 |
| 3 | 双方 | 对制冷机、样品交付时间或测试范围进行必要协调。 |
| 4 | 集成测试组 | 确认是否承接；承接后再在系统中建立专题、任务、成员安排和甘特图。 |

建议文件名：`项目名称-任务名称-测控任务需求-提交日期.md`
