# 其他小组测试需求单——填写实例

## 1. 需求信息

| 内容 | 示例填写 |
| --- | --- |
| 提出小组 | `工艺组` |
| 需求名称 | `z4readout（BGA露出）样品测试（至少2个）` |
| 测试目的 | `验证 BGA 封装通断、基础 Q 值和读取设计是否满足后续测试要求。` |
| 专题建议 | `建议归入“Z4 Readout 封装与读出验证”；不合适可由测控组调整。` |
| 制冷机要求 | `偏好祖4；如排期冲突可调整。` |
| 其他说明 | `样品正式编号需要交付后才能确定。` |

## 2. 测试项

| 测试项 | 简单说明 |
| --- | --- |
| 倒焊/焊脚间距测试 | 检查短路、开路和结构异常。 |
| Q 值测试 | 与设计预期进行比较。 |
| BGA 通断验证 | 验证通道连通性和引脚对应关系。 |
| 读取设计验证 | 验证与现有读取设计的适配性。 |

## 3. 样品

| 样品代称 | 样品型号 | 数量 | 样品编号 | 预计交付时间 | 备注 |
| --- | --- | ---: | --- | --- | --- |
| `BGA-01` | `Z4Readout-BGA露出` | 1 | `待定` | `2026-09-04` | 交付后补正式编号。 |
| `BGA-02` | `Z4Readout-BGA露出` | 1 | `待定` | `2026-09-04` | 交付后补正式编号。 |

## 4. 测控组收到后

测控组根据这份需求自行确认专题、建立任务、分配成员和制冷机，并安排甘特图测试时间；工艺组不需要再填写这些内部信息。
