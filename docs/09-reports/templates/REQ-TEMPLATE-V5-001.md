# 小组任务管理与甘特图系统

## 需求文档模板

> 适用版本：V5（桌面端）  
> 适用场景：超导量子计算测控组承接其他小组的测试需求，并进行专题归类、任务分配和甘特图排期。

## 填写说明

1. 文档按“专题 → 连续任务 → 样品”组织。一个专题可以包含多个连续任务，一个连续任务可以包含多个样品。
2. 样品未交付前，至少填写“规划标签”和“样品型号”；具体编号可以填写 `待补/TBD`，不影响提前规划。
3. 样品预计交付时间可能变化，制冷机也可能变更。每次变更请填写“计划变更记录”，再同步修改系统中的任务或执行排期。
4. 一个任务的多个样品可以绑定同一名成员，也可以绑定多名成员；请在样品表和成员排期表中写清楚关系。
5. 本模板不要求填写联系人、前置任务、任务顺序、每人工时或成果提交信息。

## 8. 系统状态规则

| 状态 | 系统判定或操作规则 | 录入时需要提供 |
| --- | --- | --- |
| 等待样品 | 人工阶段仍为“等待样品”，且任务尚未进入测试。无样品、样品 ETA 待确认、样品未到且 ETA 未过，或全部样品已到但尚未开始测试时，均保持该阶段。 | 样品型号、规划标签、预计交付日期（可待定） |
| 样品交付延期 | 人工阶段仍为“等待样品”，存在已确认 ETA 且当前日期已超过 ETA 的未到样品；ETA 待确认不自动判定延期。 | 更新样品 ETA；必要时填写变更记录 |
| 正在测试 | 由成员在系统中手动切换，表示测试已开始。 | 计划测试时间、参与成员、制冷机 |
| 测试延期 | 人工阶段已切换为“正在测试”，当前日期超过计划测试结束日期，且任务尚未切换为“已完成”。 | 修订计划测试结束时间并记录原因 |
| 已完成 | 由成员在系统中手动切换，优先级最高。 | 完成后补充备注（如有） |

> 系统不设置“已到样待测试”状态。到样信息作为样品事实记录，任务仍按上述状态规则展示。

## 9. 提交前检查

- [ ] 已填写来源小组，并与来源小组负责人确认任务范围。
- [ ] 已填写专题；暂时没有专题时已填写“无专题”。
- [ ] 每个任务均有测试目的、测试项、计划测试时间和预计样品交付。
- [ ] 每个样品均有规划标签和型号；未知编号已标记“待补/TBD”。
- [ ] 已填写制冷机；尚未确定时已标记“待定”。
- [ ] 已填写参与成员；多样品绑定关系已说明。
- [ ] 预计交付日期或制冷机发生变更时，已保留变更记录。

## 10. 系统录入映射

| 模板位置 | 系统位置 | 录入说明 |
| --- | --- | --- |
| 第 2 节 专题信息 | 任务全量编辑台 → 专题管理 | 先建专题，再把任务归入专题；没有专题可先用“无专题”。 |
| 第 3、4 节 任务信息 | 任务全量编辑台 → 新增任务/任务详情 | 任务属性集中维护，保存后同步到专题和执行中心。 |
| 第 5 节 样品规划 | 专题规划 → 样品 / 任务绑定 | 先用规划标签和型号建立样品，正式编号后再补录。 |
| 第 6 节 成员排期 | 执行中心 → 成员甘特图 | 可调整任务整体时间，也可单独调整某成员在该任务的时间。 |
| 第 7 节 计划变更 | 任务编辑 / 执行中心的时间与制冷机修改 | 每次修改前后值和原因，避免来源小组确认失去上下文。 |
