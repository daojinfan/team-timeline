## 验收场景

| 场景 | 给定 | 操作 | 预期 |
| --- | --- | --- | --- |
| AT-V5-001 一处补齐任务 | 无专题中存在字段不完整任务 | 打开一次编辑 | 可修改来源小组、专题、测试定义、样品、排期、制冷机、成员、状态、备注和颜色 |
| AT-V5-002 非空专题删除 | 专题包含 3 个任务 | 删除并选择“无专题” | 3 个任务原子迁移，无悬空任务 |
| AT-V5-003 多样品延期 | 任务 waiting，一个必需样品编号为空且 ETA 逾期，其他样品已有编号 | 访问任务树或甘特图 | 显示样品交付延期 |
| AT-V5-004 无“已到样待测试” | 任务 waiting，所有样品均已有编号 | 访问任务 | 显示等待样品，不出现新状态 |
| AT-V5-005 测试自动延期 | 任务 testing，结束日是昨日 | 跨过 Asia/Shanghai 当地日界 | 无需人工修改即显示测试延期 |
| AT-V5-006 任务平移同步 | 任务有两个不同成员日期片 | 任务平移 5 天并选同步 | 任务和两个成员的起止日都平移 5 天 |
| AT-V5-007 成员独立改期 | 任务有多个成员 | 拖拽一个成员时间片 | 只修改该成员，超出整体日期时要求确认 |
| AT-V5-008 资源改名同步 | 制冷机已被多任务引用 | 资源维护中改名 | 任务树、表单和甘特图都显示新名称，关联 ID 不变 |
| AT-V5-009 冲突预览 | 成员或制冷机已有重叠排期 | 保存或拖拽改期 | 显示具体冲突对象，确认前不写入 |
| AT-V5-010 并发保护 | 两个页面同时打开一任务 | 后保存的页面使用旧版本 | 拒绝覆盖，展示已变更字段并要求重新确认 |
| AT-V5-011 字段 canonical 回归 | 全部 V5 文档和命令边界 | 检索业务字段定义中的 `execution_state`、`test_purpose`、`task_color` | 禁用同义名不作为可写字段，只在 canonical 对照或回归场景中作为历史名称出现 |
| AT-V5-012 状态 token 回归 | 五类状态和任务自定义色 | 检查 chip、任务行和甘特图 | 状态使用固定 token+文字/图标，任务色只作 accent，不覆盖状态色 |
| AT-V5-013 默认状态独立保存 | 两个视图分别选择不同状态集合 | 保存工作区默认值并刷新页面 | 任务全量编辑台和执行中心分别应用各自集合，互不覆盖 |
| AT-V5-014 默认状态安全回退 | 本地偏好是无效 JSON、未知版本或含未知状态 | 重新加载 V5 工作区 | 页面正常载入，受影响默认集合回退到全部状态 |
| AT-V5-015 临时筛选与恢复 | 已保存默认状态后临时修改当前状态筛选 | 切换筛选并点击恢复全部状态 | 临时筛选不改默认值；恢复操作清空两个默认集合并立即显示全部状态 |

## 质量门

实现前必须重新规划实现工作包，完成 V5 目标基线批准和激活；不得直接把 V4 实现任务扩权为 V5 实现。
