## 验收场景

| 场景 | 给定 | 操作 | 预期 |
| --- | --- | --- | --- |
| AT-V5-001 一处补齐任务 | 无专题中存在字段不完整任务 | 打开一次编辑 | 可修改来源小组、专题、测试定义、样品、排期、制冷机、成员、状态、备注和颜色 |
| AT-V5-002 非空专题删除 | 专题包含 3 个任务 | 删除并选择“无专题” | 3 个任务原子迁移，无悬空任务 |
| AT-V5-003 多样品延期 | 任务 waiting，一个必需样品逾期未到，其他已到 | 访问任务树或甘特图 | 显示样品交付延期和到样进度 |
| AT-V5-004 无“已到样待测试” | 任务 waiting，所有样品已到 | 访问任务 | 显示等待样品及已到 X/Y，不出现新状态 |
| AT-V5-005 测试自动延期 | 任务 testing，结束日是昨日 | 跨过 Asia/Shanghai 当地日界 | 无需人工修改即显示测试延期 |
| AT-V5-006 任务平移同步 | 任务有两个不同成员日期片 | 任务平移 5 天并选同步 | 任务和两个成员的起止日都平移 5 天 |
| AT-V5-007 成员独立改期 | 任务有多个成员 | 拖拽一个成员时间片 | 只修改该成员，超出整体日期时要求确认 |
| AT-V5-008 资源改名同步 | 制冷机已被多任务引用 | 资源维护中改名 | 任务树、表单和甘特图都显示新名称，关联 ID 不变 |
| AT-V5-009 冲突预览 | 成员或制冷机已有重叠排期 | 保存或拖拽改期 | 显示具体冲突对象，确认前不写入 |
| AT-V5-010 并发保护 | 两个页面同时打开一任务 | 后保存的页面使用旧版本 | 拒绝覆盖，展示已变更字段并要求重新确认 |

## 质量门

实现前必须重新规划实现工作包，完成 V5 目标基线批准和激活；不得直接把 V4 实现任务扩权为 V5 实现。
