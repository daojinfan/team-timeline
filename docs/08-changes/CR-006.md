# 变更包：按 Web 字段表收敛工艺组专题、样品与任务数据

## 变更动机

当前 Web 的工艺组数据来自完整样品清单，包含 10 个专题、19 个样品和 18 个连续任务；用户提供的 Web 字段整理表只保留其中 5 个专题、9 个样品和 9 个测试任务。两者不收敛会导致专题列表、样品池和执行中心显示与当前计划不一致。

## 拟议变更

- 以 `outputs/专题信息补全模板-20260822/专题任务Web字段整理表.xlsx` 的 9 条任务为保留范围。
- 保留专题：应力和翘曲问题、倒焊工艺问题、读取驻波问题、CPW工艺片内片间工艺极限和稳定性+RDL孔周缺胶问题、低损耗约瑟夫森结工艺开发。
- 保留样品：对应 Excel 中的 9 个样品规划记录；同专题内未出现在表格中的样品改为归档。
- 重建/重挂 9 条 V3 连续任务到现有 V1 canonical 任务，补齐测试目的、测试项、排期、任务级制冷机、负责人和样品关联。

- 其他来源小组数据不修改；V2 schema/API 和代码不修改。
