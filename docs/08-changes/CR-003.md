# CR-003：专题、样品池与连续任务链

## Current baseline

BL-003 的 V1/V2 兼容岛继续保留，现有 V2 canonical 结构不改义。

## Impact analysis

新增 V3 表、接口、专题桌面闭环、任务级制冷机、多人独立工时和成果验收；V1/V2 API、CSV、JSON、备份和旧负载算法保持兼容。

## Resulting baseline

本变更形成 BL-004，激活后允许 WP-009 的 Release 开发任务启动。

## 变更内容

在不改变 V1/V2 canonical 契约的前提下，新增 schema 3、`v3_*` 领域表、`/api/v3`、专题/样品池/连续任务链桌面能力、任务级制冷机、多人独立工时及任务级成果验收。旧 V2 计划只通过人工复制预览与新专题建立一次性历史引用。

## 兼容与回滚

V2 12 表、10 索引、checksum、34 路由、V1 API/CSV/JSON/备份和旧负载算法保持原样。迁移前执行 SQLite 备份，增量迁移在事务中完成，失败停止并恢复备份；不以 reset 充当回滚。

## 排除范围

AI、自动任务生成、自动分配、手机端、登录、云部署、多用户权限、外部网络和二进制附件托管。

## 发布门

DEV-V31-A 服务端、DEV-V31-B 桌面壳、DEV-V31-C 客户端和 DEV-V31-D 集成验证均需独立审核；Release 任务必须通过迁移、兼容、API、浏览器双分辨率和回滚验证后才能验收。
