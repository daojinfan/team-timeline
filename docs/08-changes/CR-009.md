# 变更包：V5 任务全量编辑台与执行中心默认状态配置

## 变更动机

任务全量编辑台和执行中心目前把状态筛选默认固定为空（显示全部状态），用户无法为自己的常用工作范围设置进入页面后的默认状态。

## 当前基线

BL-008
## 拟议变更

- 在资源维护中增加“工作区默认值”设置区。
- 分别配置任务全量编辑台和执行中心的默认任务状态；每项支持多选，空集合表示全部状态。
- 使用版本化 `teamTaskGantt.v5Prefs.v1` 浏览器本地存储，首次使用和无效配置回退到全部状态。
- 页面首次加载或切换到相应模块时应用默认筛选；用户手动修改当前筛选不覆盖默认配置。
- 提供恢复全部状态的操作。
- 不修改 SQLite、V5 API、历史数据、V1/V2/V3 兼容边界和发布流程。
