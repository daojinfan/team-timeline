# 变更包：V3.1 详细任务卡与结构化测试信息

## 变更动机

现有 V3 任务已绑定专题、样品和任务级制冷机，但测试目的与测试内容主要埋在自由文本描述中，任务卡无法完整表达“属于哪个专题、哪个来源小组、要验证什么、具体测什么”。用户确认将任务详情升级为结构化任务卡。

## 当前基线


BL-004
## 拟议变更

- 在 `v3_topic_tasks` 增加兼容性字段 `test_purpose` 与 `test_items_json`，不改变 schema 3 checksum、V1/V2 canonical 表和既有 34 个接口。
- V3 task API 返回 `topic`、`source_group`、`cryostat` 关联对象、`test_purpose`、`test_items` 与前置任务信息；创建和更新任务支持保存结构化测试定义。
- 桌面任务卡显示专题、来源小组、制冷机、测试目的和测试项；新增任务详情编辑对话框。
- 对现有 18 个任务执行幂等回填：测试目的取所属专题目的；测试项从已导入样品清单的“测试内容”拆分，无法推断的项保留为空并支持后续补录。
