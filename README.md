# 小组任务管理与甘特图系统

这是一个个人使用版 Web 管理系统，用来管理小组成员任务、查看甘特图、统计成员负载，并保留 SQLite 数据。

## 启动

```powershell
npm start
```

访问：

```text
http://localhost:3000
```

### 认证初始化

生产模式默认要求登录。首次启动前通过环境变量提供一次性管理员账号，服务会创建
`admin` 角色并要求该账号首次登录后修改密码；账号创建完成后可移除这两个变量。

```powershell
$env:AUTH_BOOTSTRAP_USERNAME = "admin"
$env:AUTH_BOOTSTRAP_PASSWORD = "请使用至少 12 位随机密码"
npm start
```

普通用户只能读取业务数据和导出 CSV，账号由管理员在 `/api/admin/users` 创建。测试夹具
可显式使用 `createAppServer(database, { auth: false })` 关闭认证，生产代码不要使用该选项。

数据库：

```text
data/team_tasks.sqlite
```

## 推荐 Workflow

1. 打开首页先看顶部统计：成员数、任务数、进行中、逾期、重叠成员。
2. 用结构化筛选缩小范围：成员、状态、时间范围、逾期、重叠。
3. 新增任务时优先选择模板，自动带出颜色、默认周期和检查清单。
4. 点击甘特图任务条或任务卡片，在右侧维护任务详情和检查清单。
5. 根据需要编辑任务整体时间，或只编辑某个成员的个人任务时间。
6. 在任务视图勾选任务后使用批量栏统一修改状态、结束时间或归档。
7. 数据变多后使用维护页：清空日志、删除归档任务、重置示例数据。
8. 在甘特图中可点击“今天”快速回到当前日期，也可只显示有任务的成员。
9. 归档区和回收站可以恢复误归档、误删除的任务和成员。
10. 执行维护操作前，系统会显示影响数量；清理/重置时会自动下载操作前备份。
11. 定期导出任务 CSV、成员负载 CSV，或下载 JSON 备份。


任务导入：

```csv
title,description,default_start_date,default_end_date,color,status,member_names,checklist
补充实验,完成第二批样品,2026-07-01,2026-07-10,#2563eb,auto,张三;李四,样品准备;结果复核
```
